# Chart rule contribution guide skill

English | [简体中文](./README.zh-Hans.md)

This skill contains the declarative statistics shown on LibChecker's chart
page for AI Agent.

## Installation

Install with Vercel Skills using `npm`:

```zsh
npx skills add LibChecker/LibChecker-Rules
```

If you use [`vlt`](https://www.vlt.io):

```zsh
vlx skills add LibChecker/LibChecker-Rules
```

If you use [Vite+](https://viteplus.dev):

```zsh
vpx skills add LibChecker/LibChecker-Rules
```
