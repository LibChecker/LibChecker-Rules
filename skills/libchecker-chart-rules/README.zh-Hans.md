# 图表规则贡献指南 Skill

[English](./README.md) | 简体中文

本 Skill 存放 LibChecker 图表页面使用的声明式统计规则以供 AI Agent 参考。

## 安装

基于 `npm` 使用 Vercel Skills 安装：

```zsh
npx skills add LibChecker/LibChecker-Rules
```

如果您使用 [`vlt`](https://www.vlt.io)：

```zsh
vlx skills add LibChecker/LibChecker-Rules
```

如果您使用 [Vite+](https://viteplus.dev)：

```zsh
vpx skills add LibChecker/LibChecker-Rules
```
